## 🚀 Cómo Empezar

1. Clona el repositorio:
   ```bash
   git clone [URL_DEL_REPOSITORIO]
   ```
2. Abre `index.html` en tu navegador
3. ¡Listo! El sitio debería estar funcionando localmente
